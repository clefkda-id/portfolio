UKK Discount Calculator
Project Overview

An interactive discount calculation web application developed as my final practical project for the Software Engineering (RPL) competency exam (UKK). It features dynamic result tabulation and robust client-side logic.

Key Features:
  • Smart Input Validation: Prevents invalid entries (ensures original price is at least Rp 1 and discount ranges strictly between 1% and 100%).
  • Dynamic Result Table: Automatically logs calculation history in real-time right beneath the calculator.
  • Reset Functionality: Clears inputs and clears table history instantly with a single click.
  • Modern UI: Styled with a clean, responsive dark-glassmorphism aesthetic.
Tech Stack:

HTML5, CSS3 (Custom Glassmorphism), and Vanilla JavaScript.
